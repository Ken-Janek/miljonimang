# Definition of Done

Projekti töötid loetakse valmis ("Done") järgmiste kriteeriumide täitmisel:

## Functional Requirements
- [ ] Funktionaalsus vastab kasutajaloos kirjeldatule
- [ ] Funktionaalsus on testitud käsitsi
- [ ] Kõik vastuvõtutingimused on täidetud

## Code Quality
- [ ] Kood on loetav ja hästi struktureeritud
- [ ] Kood järgib projektis kehtestatud koodistiilit
- [ ] Suuremad funktsioonid on kommenteeritud
- [ ] Ei ole dead code'i ega debug kirjutisi

## Testing
- [ ] Funktionaalsus on testitud rakendusega
- [ ] Testitud on erinevad kasutusstsenaariumid
- [ ] Veakäsitlus on testitud
- [ ] Mobilne vaade on testitud (kui asjakohane)

## Documentation
- [ ] README on värskendatud vajadusel
- [ ] API dokumentatsioon on uuendatud (API muudatuste korral)
- [ ] Kasutaja juhenid on selged

## Git & Review
- [ ] Commit'id on sisukad ja selged
- [ ] Kood on üle vaadatud
- [ ] Merge konfliktid on lahendatud

## Performance & Security
- [ ] Rakendus ei ole märgatavalt aeglasem
- [ ] Ei ole turvaaugusid lisatud
- [ ] Tundlikud andmed pole hardkoditud

## Deployment
- [ ] Muudatused on mestitud main branch'i
- [ ] Testitud on staging keskkonnals (vajadusel)
- [ ] Teada olevad piirangud on dokumenteeritud

---

**Märkus**: Mõned kriteeriumid võivad olenevalt ülesandest irrelevantne olla (nt deployment, kui pole serverit). Sel juhul märki need läbi.
