📚 Mis on Miljonimäng?

Miljonimäng on veebirakendus, mis aitab õpilastel ja õpetajatel kontrollida, kas õppija saab aru programmeerimise ülesande lahendusest. Rakendus kasutab AI-tehisintellekti, et genereerida kontekstipõhiseid küsimusi millionäri-mängu formaadis.

Eesmärk: Luua interaktiivne ja motiveeriv viis õppimise valideerimiseks läbi mängu mehaanika.

🤖 AI Küsimuste Genereerimine

GPT-3.5 abil genereeritakse kontekstipõhised küsimused ülesande lahenduse põhjal

🎯 Millionäri Mängu Mehaanika

Klassikaline 15-küsimuseline mäng progressiivse raskusega ja ohutusetasemetega

💡 Kolm Lifelain

Vihje, 50:50 ja Publiku hääletus aitavad raskete küsimuste lahendamisel

📊 Randomiseeritud Küsimused

Iga mäng on erinev - küsimused ja vastused tulevad randomiseeritud järjekordas

🇪🇪 Eesti Keelne

Täielikult eesti keeles - kasutajaliides, küsimused, tagasiside

🚀 Lihtne Laiendamine

Lisage uusi ülesandeid JSON failide abil - ei vaja programmeerimist

🚀 Kiirstart

Eeldused

  • Node.js 14+
  • npm
  • Git

Paigaldamine

git clone https://github.com/Ken-Janek/miljonimang.git
cd miljonimang
npm install
npm start

Seejärel ava brauseris: http://localhost:3000

Uute Ülesannete Lisamine

  1. Loo kaust: input/002/
  2. Lisage failid: assignment.md, lahenduse failid
  3. Loo questions.json 15 küsimuse klassiga
  4. Rakendus laadib automaatselt

🏗️ Arhitektuur

  • Backend: Node.js + Express
  • Frontend: HTML5 + CSS3 + Vanilla JavaScript
  • AI: OpenAI GPT-3.5-turbo (valikuline)
  • Andmed: JSON failid (questions.json)
  • Cache: Lokaalne failisüsteem

📋 Küsimuste Formaat

Küsimused peavad olema JSON formaadis:

{
  "level": 1,
  "question": "Küsimuse tekst?",
  "options": ["Valik A", "Valik B", "Valik C", "Valik D"],
  "correctIndex": 1,
  "explanation": "Selgitus"
}
