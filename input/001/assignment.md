# JavaScripti Kalkulaator

## Ülesande kirjeldus

Loo lihtne veebirakendus, mis toimib kalkulaatorina ja suudab teostada põhilisi matemaatilisi tehted.

## Nõuded

1. **Kasutajaliides**
   - HTML vorm kahe arvusisendi väljaga
   - Nupud operatsioonide jaoks (+, -, *, /)
   - Tulemusel kuvatav väli
   - Kustutamise nupp

2. **Funktionaalsus**
   - Rakendus peab suutma liita, lahutada, korrutada ja jagada kahe arvu
   - Kasutaja saab valida operatsiooni
   - Tulemus kuvatakse HTML-lehel
   - Jagamine nulliga peab olema kontrollitud ja veateadet kuvama

3. **Kood**
   - HTML, CSS ja JavaScript failis
   - Kood peab olema loetav ja hästi struktureeritud
   - Peab kasutama event listenere kasutaja sisendi jaoks

## Hindamiskriteeriumid

### Kohustuslikud
- [ ] Kõik 4 operatsiooni töötavad õigesti
- [ ] Nulliga jagamine on ohtlikult kontrollitud
- [ ] Vale sisend (mittearv) kutsub välja veateate
- [ ] Tulemused kuvatakse korrektselt

### Soovituslikud
- [ ] Kood on hästi kommenteeritud
- [ ] CSS kujundus on puhas ja kasutatav
- [ ] Rakendus käitub korrektselt erinevate suuruste arvudega
- [ ] Ka negatiivsed numbrid ja kümnendkohad töötavad

## Näidisvastused

Vt `index.html`, `style.css` ja `script.js` faile.
