# Todo List Application

## Ülesande Kirjeldus

Loo kahe-leheküljeline TODO rakendus HTML, CSS ja JavaScriptiga. Rakendus peaks võimaldama:

### Nõuded:

1. **Ülesannete lisamine**
   - Kasutaja saab uue ülesande sisestada tekstiväljale
   - "Lisa" nupu klõps lisab ülesande loendisse
   - Enter-klahviga ka saab ülesande lisada

2. **Ülesannete kuvamine**
   - Kõik ülesanded kuvatakse nimekirjana
   - Iga ülesande kõrval on "Kustuta" nupp
   - Ülesandeid saab märkida tehtud/tegemata

3. **Ülesannete kustutamine**
   - Kustuta nupu klõps eemaldab ülesande

4. **Andmete säilimine**
   - Ülesanded salvestatakse localStorage-i
   - Lehe värskendamisel jäävad ülesanded alles

### Põhinõuded:
- Kasuta clean HTML5 struktuuri
- Kirjuta CSS juhuslikult paigutamise jaoks
- Valideeri sisendit (ära lisa tühje ülesandeid)
- Kasuta semantic HTML elemente
