# Rock-Paper-Scissors Game

## Ülesande Kirjeldus

Loo interaktiivne Rock-Paper-Scissors (Kivi-Paber-Käärid) mäng HTML, CSS ja JavaScriptiga. Mängija mängib arvutiga.

### Nõuded:

1. **Mängu loogika**
   - Kasutaja valib kivi, paberit või käärid
   - Arvuti teeb juhuslikult valiku
   - Määratu võitja ja loendatakse punkte

2. **Kasutajaliides**
   - Kolm suurt nuppu: Kivi, Paber, Käärid
   - Kuvata mängija ja arvuti valikud
   - Näita võitjat iga vooru jaoks

3. **Mängu tulemused**
   - Loe üles mängija punkte
   - Loe üles arvuti punkte
   - Kuva kogu-skoor

4. **Eriomadustused**
   - "Jäta mängu" nupp nullib skoori
   - Mälu eelmistest voorus
   - Punkte kuvatakse reaalajas

### Mängu reeglid:
- Kivi lüüab kääride
- Paber lüüab kivi
- Käärid lüüavad paberit
- Sama valik = viik
